固定版本操作指引

  1. 导入破解包 → 选中游戏点「应用锁定」（锁定 GID 写入清单）。
  2. 点「一键冷启动」：自动关 Steam、备份并清 appinfo.vdf、重开。
  3. 核对 content_log 的 Downloading GID 是锁定值，等待下载完成。
  4. 到「应用补丁」tab 选 _crack_ready 覆盖补丁，关 Steam 直接运行游戏验证。
