**Goal:** 给入库中心加一个启动自检：只读比对已锁定破解游戏（当前剑星 3489700）的本体版本与可信基线，发现被更新就告警"补丁可能失效"，只报不改。

**Tech Stack:** Python 3.14 标准库（re/os/json/tempfile）、tkinter、PyInstaller 6.22.3 onefile、pytest 9.2.0。

**Spec:** `D:\STEAM入库\全自动入库_v3\docs\superpowers\specs\2026-11-23-自动维护中心v3-design.md`

- [ ] **Step 3: 实现 `src/update_guard.py`**

按 Interfaces 的 6 个函数签名实现：
- `library_dirs()`：`P.find_steam_dir()` → 读 `steamapps\libraryfolders.vdf`，正则 `r'"path"\s+"([^"]+)"'` 取所有 path，`replace("\\\\", "\\")` 后 `os.path.normpath`，加上 steam 自身，去重（保留顺序）。
- `read_acf(appid, dirs=None)`：`dirs or library_dirs()`，逐个找 `os.path.join(d, "steamapps", f"appmanifest_{appid}.acf")`；读到用正则提 `buildid`/`TargetBuildID`/`installdir`，manifest 用 `re.findall(r'"(\d{4,})"\s*\{\s*"manifest"\s+"(\d+)"', text)`；无文件返回 None。
- `locked_apps()`：读 `os.path.join(P.writable_dir(), "crack_library.json")`，筛 `rec.get("verified") and rec.get("locked_gids")`。
- `build_baseline(force=False)`：读已有 baseline；遍历 locked_apps，read_acf 有结果才写入 `{name, buildid, target_buildid, manifest_gids, captured_at}`（已有且不 force 则保留）；`os.replace` 原子写。
- `check_updates()`：读 baseline + locked_apps；每个 app 若 baseline 无该条或 read_acf 为 None 则跳过；三判据（buildid 变化 / target!=buildid / manifest_gids 任一不符）收集 reasons；命中则附 `advice` 文案。
- `format_report(items)`：多行中文，含"补丁可能失效"和"版本锁定 tab 重锁重打"字样。
