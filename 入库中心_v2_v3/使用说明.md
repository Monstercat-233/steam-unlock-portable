# 入库中心 v2 · 使用说明

借鉴 TitanCore 设计的本地入库工具升级版。单 exe、零硬编码路径（自动找 Steam）、4 个 tab 一站式操作。**v1（`D:\STEAM入库\全自动入库\`）保持原样可随时回退。**

## 快速开始

双击 `入库中心.exe`。程序自动定位 Steam 目录和当前登录账号（下拉可切换）。

## 四个 tab

### 1. 入库
- 输入游戏名或 AppID → 点「搜索」→ 选中 → 「入库」；也可直接输 AppID。
- 「移除」删掉入库块；「打开目录」跳到 `mygames.lua` 所在目录。
- 状态栏三态：
  - 绿=可下载+可运行（老 SteamStub 单机/纯合作 PVE）
  - 黄=需票据/补丁（Denuvo 游戏，见「版本锁定」tab）
  - 红=仅显示图标（key 库无 depot key，下载不了）
- 下载后若提示「内容配置无效」：关 Steam → 删 `D:\STEAM\appcache\appinfo.vdf` → 重开 Steam（注入层改 GID 后必须冷启动才生效）。

### 2. 版本锁定（给破解游戏锁老版本）
- 破解库列已知 Denuvo 游戏（当前：剑星/影之刃零/黑神话）。
- 「应用锁定」把该游戏的 manifest GID 换成破解版锁定值。
- 「导入破解包」从你的 lua/补丁包提取 locked_gids 入库。
- 锁定后按提示关 Steam→删 appinfo.vdf→冷启动→确认 `Downloading ... (锁定 GID)` 再下。
- ⚠ `setManifestid` 第一参数必须是数字，写成字符串会被 Steam 静默忽略（v1 踩过的坑，v2 已修正）。

### 3. 补丁（打破解补丁）
- 填 AppID + 补丁包路径（`_crack_ready` 目录或 zip）。
- 程序自动按锚点（Engine/SB/Binaries…）整理相对路径。
- 「预览（dry-run）」列出将覆盖哪些文件，**只读不写**。
- 确认无误后「应用」覆盖，覆盖前自动备份到游戏目录 `_patch_backup\<appid>_<时间>\`。

### 4. 备份与隔离（轻量）
- 账号下拉默认认当前登录，可切换。
- 「创建快照」备份 config.vdf / loginusers.vdf / localconfig.vdf / mygames.lua / opensteamtool.toml + manifest.json。
- 「体检」显示：是否家庭共享、lua 块是否配对、三 DLL 哈希是否正常。
- 「回滚」从快照还原——**强制要求先退出 Steam**，否则拒绝（防占用写坏）。
- 所有操作写 `audit.log`。

## 关于「账号隔离」的实话

假入库游戏显示「来自家庭库」是 Steam **服务端账本**判定，本地工具改不了。此处的「轻量隔离」=独立配置快照 + 干净基线 + 一键回滚（翻车秒还原、不污染主号），**不改变显示**。之前试过本地清共享标记的 fork，结果是假下载（0 文件），已证伪。

## 数据与更新

- `depotkeys_master.json`（16MB / 288381 条）：depot 解密 key 库，与 exe 分开存放，可单独替换更新。
- `crack_library.json`：破解游戏库（GID 锁定值）。
- `names.json`：游戏名↔AppID 本地索引，联网查询后自动写回。
- 这 3 个文件放在 exe 同级目录即可被读取；源码模式下在 `src\`。

## 已知边界

- Steam 大版本更新后 OST 的 hook pattern 需上游跟上（联网自动拉），期间入库功能可能短暂失效；已落盘游戏/补丁不受影响。
- SteamTools 与 OST 二选一，不能共存（都劫持 `xinput1_4.dll`）。
- 只适用于无反作弊 / 纯单机 / Steamworks 票据可解的游戏；EA/Ubisoft/Xbox Live 自有账号 + 内核反作弊游戏无解。
- 破解游戏建议关闭自动更新，否则本体更新会让锁定 GID 失效。

## 回退

想回 v1：直接用 `D:\STEAM入库\全自动入库\简单入库.exe`，v1 文件全程未改。
